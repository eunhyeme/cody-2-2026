# 미션 1 기록

- AI A : Claude / 주요 대화 캡처 파일명: "이미지/모델A_claude/*"
- AI B : Gemini / 주요 대화 캡처 파일명: "이미지/모델B_gemini/*"
- AI가 물어서 내가 정한 것:
  - 사용자
    - 나 혼자 만들고 조작하고, 친구들과는 노트북 화면으로 같이 본다 (PC 위주)
  - 등급
    - 기본 S·A·B·C·D 5단계, 등급을 직접 추가하고 이름을 바꿀 수 있게 한다
  - 옮기는 방식
    - 드래그 앤 드롭과 클릭 후 등급 선택을 둘 다 지원한다
  - 카드
    - 포스터 형태로 보이고, 마우스를 올리면 제목·개봉연도·감독이 나온다
  - 포스터 이미지
    - 처음엔 AI에게 찾아달라고 했지만, 저작권 때문에 어렵다는 답을 듣고 실제 포스터 대신 영화별 색감으로 만든 포스터풍 카드로 정했다
  - 영화 목록
    - 파일의 8편으로 고정한다 (추가·삭제 없음)
  - 시작 상태
    - 처음 열면 영화가 모두 아래 '미분류' 영역에 있다
  - 등급 삭제
    - 삭제한 등급의 영화는 미분류로 돌아간다
  - 저장
    - 다시 열어도 배치가 남아 있고, 초기화 버튼도 둔다
  - 완성 기준
    - 처음엔 "8편 모두 이동"만 골랐다가, 완성 기준의 의미를 물어본 뒤 정한 기능 전부를 확인 항목 5개로 정했다

- 같은 행동으로 비교한 결과(해본 행동 → 기대 결과 → A의 결과 / B의 결과)
  - Gemini와 Claude에게 같은 기획서 파일을 첨부하고 같은 프롬프트로 html 파일을 요청했다. 
  - Claude가 UI를 잘한다는 말을 익히 들었어서 Gemini 보다 센스있는 디자인을 기대했다.
  - 예상대로 Claude가 센스있고 깔끔하게 웹페이지를 작성해줬다. 특히 호버로 특정 영화의 세부사항을 보여주는 부분이 마음에 들었다.
  - 그런데 의외로 Gemini도 깔끔하게 잘 만들어 주었다. 처음엔 궁서체로 영화를 표기하길래 UI가 못생겼다 생각했는데, 특정 영화만 궁서체를 쓰고 다른 영화도 글씨체가 미묘하게 다른 것을 보고 나름 영화 장르에 맞춰 UI를 구성했다는 생각이 들었다. 또 호버 애니메이션이 claude와는 달랐는데 이건 gemini가 마음에 들었다.
  - 기능적 차이는 크게 없었다. 인증/인가가 필요없는 웹사이트로 구성했기 때문에 두 모델 다 기획서 대로 잘 나왔다. 
   
- 선택한 파일명과 고른 이유: 영화_A_초안.html (Claude 버전)
  - Gemini 버전과 다르게 영화 블럭 크기에 맞춰 랭킹바 높이가 처음부터 설정되어있고, 무엇보다 내가 따로 요청하지 않았는데도 사용자를 위한 이용 설명문을 군데군데 배치해 두어 사용자 친화적인 UI라 생각했기 때문이다.
