# 자동 간격 마인드맵

## 대상 사용자

- 나 혼자 사용합니다. 생각이 복잡할 때 아이디어를 정리하는 용도입니다.

## 사용 목적

- 마인드맵으로 생각을 정리합니다.
- 기존 마인드맵 프로그램은 노드 간격을 직접 맞춰야 해서 번거롭습니다. 노드를 추가하거나 삭제하면 서로 겹치지 않고 적당한 간격을 유지하도록 자동으로 배치하는 것이 핵심입니다.

## 화면 구성과 동작 (필수 기능)

**시작 화면**
- 화면 가운데에 빈 "중심 주제" 노드 하나만 있습니다.

+ **시작 도움말 창**
+ 페이지에 처음 들어오거나 새로고침할 때마다 도움말 창을 띄웁니다. 반투명 배경 위에 불투명한 카드로 표시합니다.
+ 도움말 창에는 반복 재생되는 짧은 움짤 2개로 사용법을 보여줍니다.
+   - 자식 노드: 노드를 선택하고 Tab을 누르면 바깥쪽에 자식 노드가 생기는 모습
+   - 형제 노드: 노드를 선택하고 Enter를 누르면 같은 깊이에 형제 노드가 생기는 모습
+ 사용자는 언제든 창을 닫을 수 있습니다. 닫기(×) 버튼, "시작하기" 버튼, Esc 키, 창 바깥 클릭 중 아무것으로나 닫힙니다.
+ 창이 열려 있는 동안 누른 키(Tab, Enter, Delete 등)는 마인드맵에 전달되지 않습니다. 창을 닫으려다 노드가 생기거나 지워지지 않게 하기 위함입니다.
+ 운영체제의 "동작 줄이기" 설정이 켜져 있으면 움짤 대신 결과 화면을 정지 상태로 보여줍니다.

**배치 (방사형, 자동)**
- 중심 노드에서 자식 노드가 사방으로 퍼지는 방사형으로 배치합니다.
- 노드를 추가, 삭제, 수정하거나 접고 펼 때마다 전체 위치를 다시 계산합니다. 글자 길이와 줄 수에 따라 달라지는 노드 크기도 반영합니다.
- 위치가 바뀔 때는 부드럽게 이동합니다.
- 노드를 마우스로 끌어 옮기는 기능은 없습니다. 배치는 완전 자동입니다.

**깊이별 색상**
- 같은 깊이의 노드는 같은 색입니다. 색으로 깊이를 대략 알 수 있습니다.
- 깊이 1~10에 서로 다른 파스텔 색 10가지를 쓰고, 깊이 11부터는 깊이 1의 색부터 다시 반복합니다.
- 중심 노드(깊이 0)는 별도 색으로 구분합니다.

**노드 조작**
| 입력 | 동작 |
|---|---|
| 노드 클릭 | 노드 선택 |
| Tab 키 또는 "+" 버튼 | 선택한 노드에 자식 노드를 추가하고 바로 글자 입력 상태로 전환 |
| Enter 키 (선택 상태) | 형제 노드 추가 (중심 노드에서는 동작하지 않음) |
| 더블클릭 | 글자 수정 시작 |
| Enter 키 (수정 중) | 수정 완료 |
| Shift + Enter (수정 중) | 줄바꿈 |
| Esc 키 (수정 중) | 수정 취소 |
| Delete 키 | 선택한 노드를 자식 노드까지 함께 삭제 (중심 노드는 삭제 불가) |
| 접기/펼치기 버튼 | 자식 노드 숨기기/보이기. 접힌 노드에는 숨긴 자식 수 표시 |

+ **키보드로 노드 이동 (방향키)**
+ 마우스 없이 방향키로 노드 사이를 이동합니다. 이동한 노드가 선택(포커스) 노드가 됩니다.
+ | 입력 | 동작 |
+ |---|---|
+ | ↑ 키 | 부모 노드로 이동 (중심 노드에서는 안내 메시지만 표시) |
+ | ↓ 키 | 자식 노드로 이동. 마지막으로 머물렀던 자식이 있으면 그 노드로, 없으면 첫 자식으로 이동 |
+ | ← / → 키 | 이전 / 다음 형제 노드로 이동. 양 끝에서는 반대쪽 끝으로 순환 |
+ 노드가 접혀 있거나 자식이 없을 때 ↓를 누르면 이동하지 않고 안내 메시지를 표시합니다.
+ 글자 수정 중이거나 검색창에 입력 중일 때는 방향키가 원래 동작(커서 이동)을 합니다.
+ 하단 단축키 안내에 방향키 사용법을 표시합니다.

**화면 이동**
- 빈 곳을 끌면 화면이 이동합니다.
- 마우스 휠로 확대/축소합니다.
- "가운데로" 버튼을 누르면 중심 노드가 화면 가운데로 돌아옵니다.

+ **화면 따라가기 (포커스 유지)**
+ 화면은 가장 최근에 선택·추가·수정한 노드(포커스 노드)를 기준으로 유지합니다.
+ 노드 추가·삭제·수정·접기/펼치기·실행 취소 등으로 배치가 바뀐 뒤 포커스 노드가 화면 밖(가장자리 40px 여유 포함)으로 나가면, 그 노드가 화면 가운데에 오도록 부드럽게 이동합니다. 화면 안에 있으면 이동하지 않습니다.
+ 방향키로 이동한 노드가 화면 밖에 있을 때도 같은 규칙으로 화면이 따라갑니다.
+ 화면이 중심 노드 쪽으로 돌아가는 경우는 "가운데로" 버튼, JSON 불러오기, 사용자가 직접 끌어 이동한 경우뿐입니다. 그 밖의 조작으로 화면이 중심 노드로 튀지 않습니다.
+ 노드를 삭제하면 같은 자리의 다음 형제 → 이전 형제 → 부모 순으로 포커스가 옮겨집니다.

**저장**
- 변경할 때마다 브라우저에 자동 저장합니다. 새로고침해도 유지됩니다.
- JSON 파일로 내보내기/불러오기를 할 수 있습니다.

## 필요한 자료

- 깊이별 파스텔 색 10가지. 서로 어울리도록 채도와 밝기를 같게 맞추고 색상(hue)만 일정 간격으로 바꿉니다.
  - 기준: `hsl(색상, 60%, 85%)`, 색상은 0°부터 36°씩 증가 (0, 36, 72, … 324)
  - 글자색은 짙은 회색 `#333333`으로 통일해 모든 배경에서 잘 읽히게 합니다.
- 중심 노드 색: 깊이 색과 구분되는 짙은 색 배경 + 흰 글자
- 시작 노드 문구: "중심 주제"
+ 도움말 창 움짤: 외부 이미지·GIF 파일 없이 HTML/CSS 애니메이션으로 만들어 HTML 파일 하나 안에 포함합니다. 움짤 속 노드 색은 실제 깊이 1 색과 같게 맞춥니다.

## 완료 기준

- 노드를 30개 추가해도 노드끼리, 노드와 연결선이 겹치지 않습니다.
- Tab으로 자식, Enter로 형제 노드가 추가되고, 추가된 노드는 바로 글자를 입력할 수 있습니다.
- 글자 수정 중 Shift+Enter를 누르면 줄바꿈이 되고, 줄이 늘어나도 주변 노드와 겹치지 않게 다시 배치됩니다.
+ 자식 노드를 화면 밖으로 벗어날 만큼 계속 추가한 뒤 형제 노드를 추가해도, 화면이 중심 노드로 돌아가지 않고 새로 추가한 노드가 화면 안에 보입니다.
+ 페이지에 들어오거나 새로고침하면 도움말 창이 뜨고, 자식·형제 노드 만드는 움짤이 반복 재생됩니다.
+ 도움말 창은 ×, "시작하기", Esc, 바깥 클릭으로 닫히며, 열려 있는 동안 Tab·Enter·Delete를 눌러도 마인드맵이 바뀌지 않습니다.
+ 마우스를 쓰지 않고 방향키만으로 부모(↑)·자식(↓)·형제(←/→) 노드 사이를 이동할 수 있습니다.
- 깊이 11의 노드가 깊이 1의 노드와 같은 색입니다.
- 모든 노드의 글자와 배경의 명암 대비가 4.5:1 이상입니다.
- 새로고침해도 마인드맵이 그대로 남아 있고, 내보낸 JSON을 불러오면 같은 마인드맵이 복원됩니다.
- 다른 파일이나 로그인, 인터넷 연결 없이 HTML 파일 하나로 열립니다.

## 추가 기능

- 이미지(PNG) 저장
- 실행 취소 / 다시 실행 (Ctrl+Z / Ctrl+Y)
- 노드 글자 검색

## 한계 및 비목표

1. 노드를 마우스로 끌어 직접 옮기는 기능은 만들지 않습니다.
2. 트리 구조만 지원합니다. 서로 다른 가지의 노드를 선으로 잇는 교차 연결은 없습니다.
3. 모바일 터치 조작은 최적화하지 않습니다. PC 브라우저 기준입니다.
+ 4. 도움말 창은 들어올 때마다 뜹니다. "다시 보지 않기" 옵션은 없고, 닫은 뒤 다시 보려면 새로고침합니다.
+ 5. 방향키 이동은 트리 구조(부모·자식·형제) 기준입니다. 화면상 위치(위·아래·왼쪽·오른쪽)를 기준으로 가장 가까운 노드로 이동하지는 않습니다.

## 검증 방법

- **겹침**: 노드 30개(깊이 3 이상 포함)를 추가한 뒤 눈으로 확인합니다. 브라우저 개발자 도구 콘솔에서 모든 노드의 사각형 영역(`getBoundingClientRect`)을 서로 비교해 겹치는 쌍이 0개인지 확인합니다.
+ **포커스 유지**: 중심 노드에서 Tab으로 자식을 10단계 이상 이어 추가해 화면이 이동한 뒤, Enter로 형제 노드를 여러 번 추가합니다. 매번 선택된 노드가 화면 안에 있고, 콘솔에서 `document.getElementById('stage').scrollTop`이 항상 0인지 확인합니다.
+ **도움말 창**: 새로고침해 도움말 창이 뜨고 움짤 2개가 반복 재생되는지 확인합니다. 창이 열린 상태에서 Tab·Enter·Delete를 눌러 노드가 추가·삭제되지 않는지 확인한 뒤, ×·"시작하기"·Esc·바깥 클릭 각각으로 창이 닫히는지 확인합니다.
+ **방향키 이동**: 깊이 3 이상, 형제 3개 이상인 마인드맵에서 ↑·↓·←·→로 이동하며 선택 노드가 부모·자식·형제로 바뀌는지 확인합니다. ↑ 후 ↓로 원래 자식에 돌아오는지, 형제 양 끝에서 순환하는지, 화면 밖 노드로 이동하면 화면이 따라가는지, 글자 수정 중에는 방향키가 커서 이동으로 동작하는지 확인합니다.
